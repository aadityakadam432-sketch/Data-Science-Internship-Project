# Data Science Internship Project

## Project Overview

This repository contains my comprehensive Data Science internship project report and supporting work completed throughout the internship.

The project demonstrates an end-to-end Data Science workflow including:

* Data Acquisition
* Data Cleaning and Preprocessing
* Exploratory Data Analysis
* Data Visualization and Storytelling
* Statistical Analysis
* Regression Analysis
* Machine Learning
* Model Evaluation
* Strategic Recommendations

## Project Modules

### Week 1 — Data Acquisition, Cleaning and EDA

Analysis of Student Performance data including data cleaning, missing-value treatment, duplicate removal, descriptive statistics, correlation analysis, and exploratory visualization.

### Week 2 — COVID-19 Data Visualization

Analysis and visualization of COVID-19 trends, country comparisons, confirmed cases, deaths, distributions, and relationships between variables.

### Week 3 — Advertising and Sales Statistical Analysis

Analysis of the relationship between advertising expenditure and sales using correlation analysis and multiple linear regression.

### Week 4 — Machine Learning Model Development

Development and evaluation of a Logistic Regression classification model using the Breast Cancer Wisconsin Diagnostic dataset.
